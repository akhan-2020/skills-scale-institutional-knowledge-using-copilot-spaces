# Project README Template

## Purpose
Serve as the single source of truth for project status, key links, decisions, and communication cadence. This document should be the first place anyone looks to understand "what's happening with this project?"

## When to use
- Create during project initiation
- Update throughout project lifecycle
- Reference in all project communications
- Link from project boards, wikis, and documentation

## How to use
1. Copy this template to your project repository as `README.md` or `PROJECT_STATUS.md`
2. Fill in all sections during project kickoff
3. Assign a DRI (Directly Responsible Individual) to keep it updated
4. Review and update weekly during team syncs
5. Reference this document in status updates and communications
